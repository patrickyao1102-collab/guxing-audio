# guxing-audio

《孤星问道》测试版的素材站：配乐、配音、视频。

这里不放源文件，也别手改。每 10 分钟，本仓库的发布流程（.github/workflows/pages.yml）会去 [guxing-wendao](https://github.com/patrickyao1102-collab/guxing-wendao) 取出这一类只进测试版的素材，加扰后发布到 https://patrickyao1102-collab.github.io/guxing-audio/ ，测试版（guxing-wendao 的 /play/）从这里取。

分类规则见 guxing-wendao 的 tools/play/ext.json 和 tools/build_play.py。
